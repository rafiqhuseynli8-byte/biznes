# biznes — Zərf

Публичный сайт: витрина, примеры и станок для сборки заказов.

| Что | Где |
|---|---|
| Витрина для клиентов | `index.html` |
| Станок (только для себя) | `qur/index.html` |
| Тринадцать примеров | `numune/` |
| Скриншоты и карточка ссылки | `img/` |
| Инструкция | `КАК-ЗАРАБОТАТЬ.md` |
| Исходники (шрифты не вшиты) | `src/` |

Адрес после включения GitHub Pages:
`https://rafiqhuseynli8-byte.github.io/biznes/`

Правила:

- Ничего личного в `numune/` — во всех примерах имя «Aysel», телефона нет,
  кнопка ответа скрыта. Проверено запуском каждой страницы, а не чтением кода.
- `qur/` нигде не связан ссылкой и закрыт от поиска (`noindex`). Клиентам
  его показывать не надо.
- Фотографии в примерах — намеренно абстрактные пятна с подписями вроде
  «sənin şəklin burada olacaq». Никаких чужих лиц.
