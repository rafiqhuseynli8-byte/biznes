# biznes

Сайт для бизнеса. Пока пусто — начнём с нуля, в отдельном чате.

## Что нужно решить в начале

1. Что за бизнес — твой, семейный, чей?
2. Что он продаёт или делает?
3. Зачем сайт: чтобы нашли и позвонили? посмотрели цены? заказали онлайн?
4. Есть название, логотип, фотографии?
5. Язык: азербайджанский, русский, английский — или несколько?
6. Нужен свой адрес в интернете (домен) или хватит бесплатного?

## Чем этот сайт будет отличаться от подарков

Подарки — один файл, один человек, работает без интернета.

Сайт для бизнеса — наоборот: его должны **находить** незнакомые люди. Значит
нужен нормальный адрес, несколько страниц, телефон и карта на видном месте,
быстрая загрузка на слабом интернете и текст, написанный для клиента, а не
для красоты.

Поэтому он и живёт отдельно от личного.
