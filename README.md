# biznes — магазин подарочных страниц

Публичный сайт. Здесь лежит витрина и примеры — всё, что видит клиент.

| Файл | Что это |
|---|---|
| `index.html` | сама витрина: примеры, шаги, цены, кнопка WhatsApp |
| `numune/` | двенадцать примеров, открытых для всех |
| `КАК-ЗАРАБОТАТЬ.md` | инструкция: как включить сайт и как делать заказы |
| `src/index.html` | исходник витрины (шрифты не вшиты, для правок) |
